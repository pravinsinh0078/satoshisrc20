What is SRC-20?

SRC-20 is a token standard built on the Bitcoin blockchain that enables the creation of fungible tokens through the Bitcoin Stamps protocol. The name stands for "Bitcoin Secure Tradeable Art Maintained Permanently".

Unlike conventional digital art storage that relies on centralized servers or third-party platforms, SRC-20 art is embedded directly and permanently into Bitcoin's blockchain, ensuring true decentralization and permanence.

SRC-20 was introduced in March 2023 by a developer known as Mike In Space, emerging alongside the wave of Bitcoin-native protocols following the rise of Bitcoin Ordinals and BRC-20.

⚙️ How Does SRC-20 Work?

The Encoding Process

SRC-20 art is created by converting an image file into a base64-encoded string. The encoding attaches the prefix "STAMP:" to the string and places it in the description key of a Bitcoin transaction. The transaction is then broadcast across the Bitcoin network, where nodes validate it and recompile the data into its original form.

🔐 UTXO Storage: The Key to Permanence

The critical difference between SRC-20 and other Bitcoin protocols lies in where the data is stored. Instead of being written into witness data like BRC-20, Stamp data is embedded directly into Bitcoin's Unspent Transaction Output (UTXO) set using Pay-to-Script-Hash (P2SH) transactions. UTXOs are discrete units of cryptocurrency that full nodes must maintain to verify new transactions. Data stored in UTXOs cannot be pruned or selectively removed, giving SRC-20 tokens unprecedented permanence.

🎨 Supported Formats

SRC-20 art supports image files in JPG, GIF, PNG, and SVG formats. The recommended resolution is 24x24 pixels, though creators can encode higher-resolution files at the cost of higher transaction fees.
